tracewatch

An experiment: run a command under a Linux process tracer and an intercepting HTTPS proxy, then turn the recording into a report you can click around in. These are real reports from example runs. Each is a single self-contained HTML file with no external requests. Everything below is from sanitized copies: paths, names and IP addresses are placeholders.

Scripted demo

A scripted workload against local servers: findings of every severity, a connection that bypassed the proxy, websockets, secrets that were redacted, and a dropped binary.

Things to try
  • Start on the Overview: the summary, then the ribbon of notable steps.
  • Open Process tree (3) and click a node.
  • Open Findings (2) and expand “About this rule” on any card.

A simulated intruder

A harmless, local-only simulation of an attacker’s session: decoy credential theft, a reverse-shell-shaped command to a loopback listener, obfuscated payloads that only echo, curl | sh, and a process posing as a system daemon.

Things to try
  • Findings (2): open the reverse-shell finding, then “Rule reference” at the bottom.
  • Overview: hold Ctrl and scroll over the activity lanes to zoom.
  • Click a mark in the Findings lane to open it.
